# Mac 交换区只读浏览器

适用于本次核验的 EdpEDisk 介质和当前 Apple Silicon Mac。2026-10-26 已通过本机输入的真实 U 盘口令完成密钥校验，识别交换区 exFAT 文件系统，列出根目录 20 条记录，并下载验证一个 522,016 字节的 PDF。原盘未写入。

## 使用

1. 连接 U 盘，保持“启动区”挂载。
2. 双击“启动只读浏览器.command”。保留完整项目目录；启动器使用项目内已安装的 Python 环境。
3. 在新出现的 Terminal 窗口输入 Mac 管理员密码。辅助进程仅核验设备并打开 O_RDONLY 句柄，交给普通用户进程后退出。
4. 自动打开本机页面后，输入 **U 盘交换区密码**。这是 U 盘自身密码，与 Mac 管理员密码用途不同；不要发到聊天。
5. 密码、密钥和文件系统检查均通过后，页面会列出目录，可逐个下载文件。下载不会修改原盘。
6. 用完点击“关闭读取会话”，再正常推出 U 盘。

页面只监听 127.0.0.1，入口包含随机会话路径，不连接外部服务。密码和解包后的密钥不写入配置、报告、命令参数或日志。错误口令在本机校验后停止，不向固件提交解锁尝试。程序没有写盘接口；没有实现 Finder 挂载或写回。

## 已验证与未验证

- 已验证：真实分区元数据、客户端正常密码派生和密钥解包的合成测试、驱动 SM4 标准向量和随机向量、合成加密 FAT 文件系统的完整浏览与下载路径、错误口令拒绝、跨来源请求拒绝、源镜像保持不变。
- 已完成真实验证：口令与密钥校验、exFAT 文件系统识别、根目录列出、一个 PDF 下载与保存副本 SHA256 校验，以及 PDF 首尾结构标记检查。未逐个验证全盘文件。
- 文件系统由本地 pytsk3/Sleuth Kit 识别。遇到不支持或不一致的布局时停止，不修复、不格式化。

## 实现与依赖

`reader.py` 为普通用户的本地浏览器服务，`open_device.py` 为限定的管理员辅助程序；密码仅交给本地服务。`sm4.c`、`sm4_tables.h` 和 `libsm4.dylib` 提供本机纯运算。`native_crypto.py` 用于元数据兼容解码。

当前项目的隔离环境已有 pytsk3 20260715。重建原生运算库：

```bash
clang -O3 -Wall -Wextra -dynamiclib sm4.c -o libsm4.dylib
```

本工具仍为针对本介质的兼容实现，尚未验证其他型号、重新格式化后的介质或不同策略。
