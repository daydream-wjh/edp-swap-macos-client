# 发布范围与敏感数据

本仓库是 EDP 交换区 macOS 客户端的**源码与文档仓库**，不是设备数据仓库。整理上传时按下面口径裁剪。

## 一、进仓库

- 源码：`outputs/启动程序源码/edp.swift`、Python 工具（`reader.py`、`mirror_core.py`、`mirror_server.py` 等）、`work/` 下的分析与测试脚本。
- 文档：`docs/reports/`、`docs/history/`、各目录 README、使用说明。
- 可复现证据：`outputs/验证证据/`、`outputs/静态分析证据/`、`work/analysis/` 的 asm/json、`work/device-metadata/` 的 JSON 结论。
- 交付二进制：`edp-mount`、`edp-universal`、`libsm4.dylib`（体积小，可直接用；也可用 `scripts/build.sh` 重建）。

## 二、不进仓库

| 路径 | 内容 | 原因 |
|---|---|---|
| `outputs/交换区读写工作区/` | `基线镜像.raw`、`工作镜像.raw`（逻辑 53 GiB ×2，稀疏）、`回滚记录/*.sqlite3`、`.active.lock` | 体积 + 真实设备数据 |
| `work/rw-tests/` | 测试镜像、`encrypted-source.bin`、各 workspace 与 recover 目录 | 体积 + 真实设备数据 |
| `work/usb-copies/` | `EdpEDisk.exe`、`EdpEDiskCtrl.extracted.dll`、`edpedisk_gjdw.dll`、`.sys`、`.chm` | 厂商版权，静态分析对象不外发 |
| `outputs/交换区导出/` | 从真实交换区导出的 PDF | 真实业务文档 |
| `work/device-metadata/*.bin` | `head.bin`、`tail.bin`、`stored-identity.bin`、`header-decoded.bin`、`partition-decoded.bin` | 真实设备身份与分区原始字节 |
| `work/analysis-env/` | Python 隔离环境（capstone、unicorn 等） | 可重建，平台相关 |
| `work/exfat-upstream/` | 第三方 exFAT 源码副本（含其 `.git`） | 独立上游仓库 |
| `work/reader-session/`、`*.lock`、`.last_session` | 运行时套接字与随机会话状态 | 不可复现 |
| `archive/backups/` 中的 `edp-mount*` | 旧构建产物 | 可用 `scripts/build.sh` 重建 |

`.gitignore` 与上表一一对应。文本类备份（`edp.swift`、`.command`、`使用说明.txt`）保留在 `archive/backups/`，用于对照修复前后的差异。

## 三、复算与核对

```bash
python3 scripts/check_excluded.py           # 有明细的分组逐文件比对 SHA256
python3 scripts/check_excluded.py --strict  # 文件缺失也判失败
```

`docs/排除文件清单.json` 只对**小体积、需要固定身份**的分组记录逐文件哈希（厂商二进制、导出文档、设备元数据、备份二进制）；
镜像与虚拟环境类分组仅记录文件数与总体积，因为重新哈希上百 GB 不现实。

## 四、原始工作目录

外置文件仍留在原工作目录，删除或移动会破坏现有工具的相对引用与回滚记录。需要归档时整目录打包离线保存，不要提交进仓库。

## 五、公开状态与匿名化

仓库已设为公开。公开前做了一次名称匿名化，把真实工作文件名替换为占位名，**条目数、类型、大小与 SHA256 全部保持原样**，
证据的可核对性不变：

| 位置 | 处理 |
|---|---|
| `outputs/交换区根目录.txt` | 文件名 → `样本-文件-NN`，文件头注明匿名化 |
| `outputs/真实读取验证.json` | `export_path` 改为仓库相对路径 `outputs/交换区导出/样本-文件-01.pdf`，附 `note` |
| `outputs/验证证据/U盘复测-20261027.json`、`U盘速度与功能复测-20261027.json` | 键名 → `样本-文件-NN` |
| `work/修复回归/真盘原文件基准.json` | 键名 → `样本-文件-NN` / `样本-测试-NN` |
| `docs/排除文件清单.json` | 条目路径同步替换，并加 `"name_anonymized": true` |

真实名称只保留在本机，未进入任何提交（历史提交也没有：匿名化发生在首次公开之前，且 `git log -p` 可复核）。

公开前已核验：

```bash

```
