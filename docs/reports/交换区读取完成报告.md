# Mac 交换区读取完成报告

日期：2026-10-26。

## 实际完成

已在本台 Apple Silicon Mac 上，以用户在本机页面输入的 U 盘交换区密码完成口令和密钥校验，并通过原生只读兼容实现读取交换区。没有启动 Windows 客户端、安装 Windows 驱动或使用虚拟机。

- 交换区：起始 LBA 20480，大小 56,598,069,248 字节，约 56.6 GB。
- 元数据版本：0x206；实际数据算法：SM4。
- 文件系统：exFAT，已由文件系统解析库实际识别。
- 根目录：20 条记录，其中 1 个目录、19 个文件。
- 已实际下载一个 522,016 字节的 PDF，保存于本目录的“交换区导出”文件夹。
- 下载字节数与文件系统记录一致，保存副本 SHA256 为 `2d8230ce1d54db45dd74b6e2ed7d36797b2681a41ac58c270e2e3bc4d720cb6d`；PDF 文件头和 EOF 标记检查通过。未对 PDF 内容作专业审核，也未逐个校验全盘文件。

## 可用入口

“交换区只读浏览器”目录包含可执行的“启动只读浏览器.command”、源代码、原生运算库与使用说明。当前会话已打开本机页面，可浏览目录并下载文件；后续可双击启动器重新建立会话。

此实现提供浏览和导出，没有把交换区挂载成 Finder 磁盘，也没有实现写回。最终完成的是本轮要求的“读取交换区”。

## 安全与数据状态

管理员辅助进程仅在核验设备后以 O_RDONLY 打开原始设备，把句柄交给普通用户读取进程后退出。本机服务仅监听 127.0.0.1，使用随机会话路径，并拒绝不匹配来源的提交。

没有格式化、修复分区、修改固件、变更设备节点权限或向设备提交口令猜测。应用程序没有写盘路径；口令仅在本机页面输入，密钥仅在读取进程内存中使用，没有写入口令文件、报告、命令参数或日志。

本实现按正常口令派生和密钥校验路径读取，没有修改认证判断。本轮没有验证管理平台对第三方兼容实现的支持或审计表现，不能把成功读取表述为厂商支持认证。

## 用完与重启

在页面点击“关闭读取会话”以释放密钥和设备句柄，再正常推出 U 盘。若直接拔盘，后续读取会失败；重新连接后需重新启动读取会话。

不要移动或删除项目的 `work/analysis-env`，启动器使用其中的本地依赖。项目和工具源码均保留在当前工作目录，未安装系统级服务。
