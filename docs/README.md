# 项目文档

本项目解决的是「国网内网配发的 EDP 加密 U 盘在 macOS 上打不开交换区」这件事：厂商只提供 Windows 客户端，
macOS 受 SIP 与 DriverKit 限制无法加载驱动，因此改为用户态解密 + 稀疏镜像 + 挂载 + 加密写回。
项目定位、能力边界与验证状态见 [根目录 README](../README.md)。
