# EDP 交换区 · macOS 客户端

在 macOS 上读写「EDP 加密 U 盘」的**交换区**（约 56.6 GB，SM4 加密，exFAT），并把它挂到访达里当普通磁盘用。
同一套代码还提供只读浏览器（本机网页浏览/下载）和读写工作区（镜像 + 加密写回 + 回滚记录）。

装置：EAGET EDP 加密 U 盘，`VID 0x0DD8 / PID 0x2005`（国网定制版）。平台：macOS 13+，Apple 芯片与 Intel 通用。

```
U 盘（密文） ──解密──► 本机稀疏镜像（明文） ──挂载──► /Volumes/交换区
                              ▲                            │
                              └────── 编辑后加密写回 ◄──────┘
```

macOS 无法加载厂商 kext、也没有 DriverKit entitlement，所以只能在用户态做等价模拟：
中间必然有一层本机副本，因此**必须有「写回」这一步**，不存在零延迟方案。

## 能力边界

| 区域 | 支持 | 说明 |
|---|---|---|
| 启动区（10.5 MB FAT32） | 只读使用 | macOS 原生可见，放启动脚本与 Windows 客户端 |
| **交换区（约 56.6 GB）** | **读写** | 本项目目标区域，SM4-CTR，元数据版本 `0x206` |
| 保密区 | 不触碰 | 需要更高权限，本项目不做任何访问 |
| 固件 / 口令 / 绑定信息 | 不修改 | 全程只读设备元数据 |

不格式化、不修复分区、不改设备绑定、不碰保密区。口令只在本机内存/钥匙串里用，不写明文、不联网。

## 快速开始

### 作为使用者

1. 插入 U 盘，等访达出现「启动区」。
2. 双击 `outputs/启动程序源码/安装免密码.command`（只需一次）：输一次 Mac 管理员密码安装本机帮助程序，再输一次交换区密码存进钥匙串。
3. 以后双击 `EDP交换区.command`，自动挂载到 `/Volumes/交换区`；退出时用菜单里的「保存 / 保存并退出 / 保存并弹出」。

详见 [使用说明](outputs/启动程序源码/使用说明.txt)。
保存行为：刷新 → 加密写入 → **本次所有改动区间回读校验**；短读或校验不一致即返回失败，失败不继续退出或弹盘。

### 作为开发者

```bash
./scripts/build.sh     # swiftc 分别编 arm64 / x86_64，lipo 合成通用二进制
./scripts/verify.sh    # 结构 + 哈希 + Python 语法 + 工作区干净度自检
```

Python 工具（只读浏览器 / 读写工作区）需要本机隔离环境，按各自目录下的 `requirements.txt` 重建：

```bash
python3 -m venv work/analysis-env
work/analysis-env/bin/pip install -r "outputs/交换区只读浏览器/requirements.txt"
```

## 数据与隐私

仓库只收源码、文档和可复现证据。**设备镜像、真实设备数据、厂商二进制、本机环境一律不入库**：

| 排除项 | 原因 |
|---|---|
| `outputs/交换区读写工作区/` | 稀疏镜像逻辑容量 53 GiB ×2 与回滚数据库，含真实数据 |
| `work/rw-tests/` | 读写回归工作区，含真实数据 |
| `work/usb-copies/` | 厂商 Windows 客户端与驱动二进制，版权归厂商 |
| `outputs/交换区导出/` | 从真实交换区导出的业务文档 |
| `work/device-metadata/*.bin` | 真实设备身份与分区原始抓取 |
| `work/analysis-env/`、`work/exfat-upstream/` | 本机 Python 环境、第三方上游源码副本 |
| `work/reader-session/`、`*.lock`、`*.sqlite3` | 运行时套接字、锁与回滚数据库 |

逐项文件数、体积与 SHA256 见 [排除文件清单](docs/排除文件清单.json)；用 `python3 scripts/check_excluded.py` 在原始工作目录复算比对。说明见 [发布范围与敏感数据](docs/发布范围与敏感数据.md)。

## 版本与验证口径

`outputs/启动程序源码/edp.swift` 是本仓库的 Swift 源码，`edp-mount` / `edp-universal` 是当前构建产物。
Python 工具是另一套独立实现，按各自说明使用。

报告与日志记录的是**当时**的验证结果；最近的仓库整理没有重新执行真实设备读写、安装、挂载或部署。
历史性能数字与现行说明冲突时，以源码和对应日期的验证证据为准。
